第一次使用 · 按顺序完成

① 创建 GitHub Token

点击 打开 GitHub Token 创建页面 ↗，选择 Fine-grained token。

Repository access 选择 Only select repositories，只勾选 ez2009/study-flow。

Repository permissions → Contents 设为 Read and write，其他权限保持默认，然后生成并复制 Token（通常以 github_pat_ 开头）。

② 填写下面两项

GitHub Token 是访问仓库的授权凭证；加密密码由你自己设置，不是 GitHub 登录密码。加密密码至少 10 位，所有设备必须使用同一个密码。

③ 保存 Token 并首次同步

点击「保存 Token」，再点击「立即同步」。如果云端还没有数据，网页会询问是否把本机数据作为首次备份上传；确认前请先检查本机资料是否完整。

④ 在其他设备使用

在另一台设备打开 STUDY FLOW，重新填写该设备可用的 GitHub Token，并输入完全相同的加密密码，再按提示下载云端数据。

更多连接与安全说明

• Token 只保存在当前浏览器。换设备或浏览器需要重新配置；Token 到期后，请在 GitHub 重新创建并替换。

• 本项目只请求 ez2009/study-flow 仓库的 Contents 内容读写权限。不要授予不必要的其他权限。

• 云端数据使用 AES-256-GCM 加密后再上传。仓库是公开仓库，因此不要把明文备份、API Key、Token 或其他秘密提交到仓库。

• 加密密码不会上传或保存在浏览器。请自行妥善保管；忘记密码无法恢复云端数据。

• 云同步数据存放在独立的 study-flow-data 分支，不会与网站代码所在的 main 分支混在一起。

• 如果检测到云端版本被其他设备修改，自动同步会暂停，避免静默覆盖。请先选择下载云端或上传本机覆盖。

• 首次连接前建议先点击上方「导出完整备份」，保留一份本机 JSON 备份。

使用说明
1. 先在「教辅资料库」录入资料和章节。
2. 在「任务中心」创建学校作业或其他待办。
3. 在「智能计划」选择本周末要完成的章节与任务。
4. 检查并调整自动生成的时间表，然后保存。
5. 在「学习执行」中计时、更新题数和页数。
6. 在「统计复盘」回顾本周表现。
